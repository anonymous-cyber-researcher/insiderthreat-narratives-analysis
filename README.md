# Reproducibility and Research Materials

This repository contains the data, coding materials, scripts, JSON outputs, and generated results used in this study. The repository is organised into two main folders:

```text
.
├── code/
└── data/
```

## 1. Data

The `data/` folder contains the materials used during the development and analysis of the case studies.

It includes:

* **Case studies** – the case study reports used for analysis, provided in Word format.
* **Coding guides** – different versions of the coding guide developed during the study.
* **Schemas** – different versions of the structured coding schema.
* **Templates** – different versions of the coding/output templates.

### Reproducing the study

When reproducing the work, please start with the **latest version** of the:

1. Schema
2. Coding guide
3. Template

Earlier versions are included to document the development and refinement process.

---

## 2. Code

The `code/` folder contains the scripts, intermediate data, generated JSON outputs, and results used in the analysis.

The main subfolders include:

### `code-using-llm/`

Contains the code used to process the case studies using the LLMs and generate structured outputs.

### `cohens-kappa-calculation/`

Contains the materials used to calculate Cohen's kappa for inter-coder agreement.

This folder includes:

* CSV versions of the case study coding data
* Python scripts used for the calculations
* Generated agreement/reliability results

The scripts can be used to reproduce the reported inter-coder reliability analysis.

### `agreed-json/`

Contains the **adjudicated reference JSON data**.

These JSON files represent the final agreed/reference annotations produced through the human coding and adjudication process.

### `gpt-coded-json/`

Contains the **JSON outputs generated by GPT** when processing the case studies.

### `llama-coded-json/`

Contains the **JSON outputs generated by Llama** when processing the case studies.

The `agreed-json/` folder therefore contains the reference data, while `gpt-coded-json/` and `llama-coded-json/` contain the corresponding LLM-generated outputs.

---

## Generated Results

The repository also includes the **generated results files** used in the study.

These results are provided to make the reported analyses easier to verify and reproduce without requiring the entire analysis pipeline to be rerun.

---

## Recommended Reproduction Order

For researchers wishing to reproduce the study, the following order is recommended:

1. Review the latest **schema**, **coding guide**, and **template** in the `data/` folder.
2. Review the case studies used in the analysis.
3. Use the code in `code-using-llm/` to generate the LLM-based structured outputs.
4. Compare the generated outputs with the adjudicated reference data in `agreed-json/`.
5. Use the materials in `cohens-kappa-calculation/` to reproduce the inter-coder agreement calculations.
6. Review the generated results files to compare the reproduced results with those reported in the study.
